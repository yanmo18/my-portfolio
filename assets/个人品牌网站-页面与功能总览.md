# 个人品牌网站 - 项目总览

> 更新时间：2026-05-02
> 技术栈：Vue 3 + Vite + Tailwind CSS + Vue Router 4 + vue-i18n + Laf云函数 + Vercel
> 配色：白底主色 + 红色点缀(#e63946) + 黑色文字
> 风格：极简干净、高级设计感、大标题、字体层级强

---

| # | 页面 | 类型 | 说明 |
|---|------|------|------|
| 1 | 首页 | 公开 | 左侧固定栏+右侧滚动内容+电梯导航 |

## 页面一：首页

### 布局（三栏）
- **左侧固定栏**：头像、姓名、身份标签、基本信息、技能环形进度、下载简历按钮
- **右侧主内容区**：纵向滚动，全宽分区展示
- **最右侧**：悬浮电梯导航（滚动自动高亮）

### 主内容区滚动分区

| 区域 | 展示方式 | 进入动画 |
|------|---------|---------|
| 关于我 | 全宽文字段落，红色大标题 | 从左淡入 |
| 获奖证书 | 列表+左侧红色竖条 | 逐条交错出现 |
| 项目展示 | 3×2卡片网格 | 卡片依次上滑 |
| 校园经历 | 时间线 | 从右交错滑入 |
| 联系方式 | 图标+文字 | 底部淡入 |

### 交互效果
- 滚动触发进场动画（元素进入视口才出现）
- 鼠标移动响应式动画
- 项目卡片悬浮虚化放大效果
- 中英文切换
- 响应式（移动端左侧栏收起）

---

## 页面二：项目详情弹窗

- 暗色卡片(#1a1a1a)浮在白底，红色发光圆角边框
- 关闭X按钮、项目标题、红色星芒分隔线
- 技术栈标签（选中态红色边框）、项目截图、功能编号列表
- 底部GitHub红色按钮

---

## 页面三~七：管理后台

统一右侧电梯导航切换，包含：
- 项目管理：卡片网格+添加/编辑/删除/排序
- 个人信息：头像/姓名/标签/技能/联系方式
- 奖项证书：列表增删改查
- 在校经历：时间线增删改查
- 简历管理：PDF上传/替换/预览

---

## Laf后端接口（16个）

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/projects | GET | 获取所有项目 |
| /api/projects | POST | 添加项目 |
| /api/projects/:id | PUT | 编辑项目 |
| /api/projects/:id | DELETE | 删除项目 |
| /api/profile | GET | 获取个人信息 |
| /api/profile | PUT | 更新个人信息 |
| /api/awards | GET | 获取奖项列表 |
| /api/awards | POST | 添加奖项 |
| /api/awards/:id | PUT | 编辑奖项 |
| /api/awards/:id | DELETE | 删除奖项 |
| /api/experience | GET | 获取经历列表 |
| /api/experience | POST | 添加经历 |
| /api/experience/:id | PUT | 编辑经历 |
| /api/experience/:id | DELETE | 删除经历 |
| /api/resume/upload | POST | 上传/替换简历PDF |
| /api/upload | POST | 通用图片上传 |
