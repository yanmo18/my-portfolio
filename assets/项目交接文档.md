## 二、项目结构

```
my-portfolio/
├── src/
│   ├── api/                    # API 接口层

│   │   ├── awards.js          # 奖项管理 API

│   │   └── upload.js          # 简历上传 API
│   ├── views/                  # 页面组件
│   │   ├── Home.vue           # 首页
│   │   ├── 404.vue           # 404 页面
│   │   └── admin/            # 管理后台
│   │       ├── AdminLayout.vue       # 管理后台布局
│   │       ├── AdminProfile.vue      # 个人信息管理
│   │       ├── AdminProjects.vue     # 项目管理
│   │       ├── AdminAwards.vue       # 奖项管理
│   │       ├── AdminExperience.vue   # 经历管理
│   │       └── AdminResume.vue      # 简历管理
│   ├── components/             # 公共组件
│   ├── composables/            # 组合式函数
│   ├── i18n/                  # 国际化配置
│   │   ├── index.js
│   │   ├── zh.js              # 中文
│   │   └── en.js              # 英文
│   ├── router/                # 路由配置
│   │   └── index.js
│   ├── App.vue
│   └── main.js
├── public/                    # 静态资源
│   ├── favicon.ico
│   └── 张雅岚202302030319.jpg  # 头像图片
├── scripts/                   # 构建脚本
│   ├── coze-preview-build.sh  # 预览构建
│   ├── coze-preview-run.sh    # 预览运行
│   ├── build.sh               # 部署构建
│   └── run.sh                 # 部署运行
├── index.html
├── vite.config.js
├── package.json
├── pnpm-lock.yaml
└── vercel.json               # Vercel 部署配置
```

## 六、API 接口

### Laf 后端地址
```
https://yfusw1tpgp.sealoshzh.site/api
```

### 接口列表
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/profile | 获取个人信息 |
| PUT | /api/profile | 更新个人信息 |
| GET | /api/projects | 获取项目列表 |
| POST | /api/projects | 添加项目 |
| PUT | /api/projects/:id | 更新项目 |
| DELETE | /api/projects/:id | 删除项目 |
| GET | /api/awards | 获取奖项列表 |
| POST | /api/awards | 添加奖项 |
| PUT | /api/awards/:id | 更新奖项 |
| DELETE | /api/awards/:id | 删除奖项 |
| GET | /api/experience | 获取经历列表 |
| POST | /api/experience | 添加经历 |
| PUT | /api/experience/:id | 更新经历 |
| DELETE | /api/experience/:id | 删除经历 |
| GET | /api/resume | 获取简历 |
| POST | /api/resume/upload | 上传简历 |

## 七、运行命令

```bash
# 进入项目目录
cd my-portfolio

# 安装依赖
pnpm install

# 开发预览
pnpm dev

# 生产构建
pnpm build

# 本地预览构建结果
pnpm preview
```
