# 项目截图放哪里？

把图片放到本目录对应子文件夹，每个项目 **3 张**，命名：

`1.jpg` / `2.jpg` / `3.jpg`

（也可用 `.png` / `.webp`，改扩展名后同步改 `src/api/mockData.js` 里的路径。）

| 文件夹 | 对应项目 | 线上路径示例 |
|--------|----------|--------------|
| `mall/` | 会员商城与门店运营（实习） | `/projects/mall/1.jpg` |
| `portfolio/` | 个人作品集网站 | `/projects/portfolio/1.jpg` |
| `medical/` | 国外医疗 Web 静态页 | `/projects/medical/1.jpg` |
| `market/` | 微信小程序商城（校内实训） | `/projects/market/1.jpg` |

完整磁盘路径示例：

`my-portfolio-frontend/public/projects/market/1.jpg`
